# Character Menu Design

## Goal

Create a first public-facing landing screen for Ded Cartoons where visitors select Keladd or Dander from the supplied menu art and watch that character's animation.

## Experience

The landing page displays `MENU 1.png` as a full-window scene with a compact title lockup. Two accessible, invisible hotspot buttons sit over the illustrated faces. Selecting a hotspot opens a modal video player, starts only that animation, and provides a close control, Escape-key handling, and a return to the menu. The initial page does not autoplay or download either full video.

## Constraints

- Use only the supplied visual and video files; do not invent band material.
- Keep all Git operations for the repository owner: no commits, pushes, branches, or worktrees.
- The initial build must work without a framework or runtime dependency.
- Keep the scene legible at desktop dimensions and usable on narrow screens.
